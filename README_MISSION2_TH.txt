1) เข้า MindAR Image Targets Compiler
   https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2) อัปโหลด target-card2.png
3) กด Start
4) กด Download
5) เปลี่ยนชื่อไฟล์ที่ได้จาก targets.mind เป็น:
   targets2.mind

จากนั้นให้อัปโหลดไฟล์เหล่านี้เข้า Repository เดิม ar-farm-tool-hero:
- mission2.html
- targets2.mind
- trowel.svg
- target-card2.png
- mission2-qr.png
(จะอัปโหลด demo2.html ด้วยก็ได้)

เมื่อ GitHub Pages deploy เสร็จ:
- สแกน QR บน target-card2.png
- เปิดกล้อง
- ส่องกลับไปที่การ์ดภารกิจที่ 2
